# WP-H1-11 — Representative real-asset Juego2 bridge slice

Status: PLANNED / NOT_STARTED
Class: FOUNDATIONAL INTEGRATION
EXECUTION_REQUIREMENT: LOCAL_UNITY_REQUIRED
Depends on: `WP-H1-10` PASS
Blocks: `WP-H1-GATE`

## Objective and central claim

Expand the already-adopted H1-04 Quaternius Source baseline into one representative real-asset slice and prove that the accepted catalogue, binding, materialization, component, validation, reconciliation and reconstruction contracts handle the hierarchy/material/pivot/rig/animation shapes required for the H1 parity scenario.

This is **not** the first point at which Quaternius enters the project. Real source assets have been used since H1-04. H1-11 is the broad end-to-end conformance challenge over a larger, deliberately representative subset before the Gate.

## WHY_THIS_BOUNDARY

Generic bridge correctness over a bounded early source slice can pass while a broader real hierarchy/material/rig/animation composition still breaks. H1-11 therefore owns the representative composition/conformance proof, while H1-04 owns initial source adoption/catalogue identity and later H2/ART/CITY work owns production-art creation/adaptation. A WP per asset would be absurd fragmentation.

## Inherited guarantees

H1-04 through H1-10 complete catalogue, projection, prefab, component, validation, reconciliation and reconstruction guarantees over the accepted Quaternius Source baseline; HK00A owns dependency/IP policy; `SETTING`/`VISUAL_BIBLE` own art direction; CITY-00 owns spatial-constitution shape.

## Remaining-work compression amendment

Binding planning amendment: `Docs/workpacks/H1/H1_REMAINING_COMPRESSION_AMENDMENT.md`.

H1-11 is conformance-first with a `ZERO_CODE` target outside selected-source manifest/import-configuration evidence. The Worker must first execute the representative real-source slice exclusively through accepted H1-04..H1-10 capabilities. A failure in an accepted generic guarantee routes back to its causal owner rather than being patched here. H1-11 may implement only a genuinely new in-boundary import/pivot/scale/rig/animation-shape compatibility requirement exposed by the broader real source; it may not build real-asset-specific duplicates of catalogue, materialization, prefab, component, validation, reconciliation or checkpoint subsystems.

## New guarantees owned

- representative source-slice manifest expanding the accepted H1-04 adoption baseline without redefining its legal/source authority;
- reproducible import/adaptation-for-Unity recipe and logical catalogue mapping for the representative slice;
- effective support for nested hierarchy, shared materials, pivots/scales, humanoid rig and idle/walk/sit clip references in the selected slice;
- real asset package remains replaceable and non-authoritative;
- one end-to-end real-source scenario traverses the accepted public bridge rather than only isolated synthetic fixtures.

## Explicitly not re-proved

H1-04's initial source/license adoption decision, every generic bridge invariant, every asset in the purchased source distribution, final art quality, Cantabrian art conversion, clothing/wardrobe completeness, missing prop/mesh production, missing animation production, gameplay animation behavior or H2 town production.

## Allowed scope

Approximately 10–15 source pieces from the already-approved Quaternius Source baseline: wall modules, roof, door, window/shutter, small props, lamp, tree, rock, one humanoid and three civilian clips; expanded slice manifest; deterministic Unity import settings/adaptation outputs needed only for bridge compatibility; bridge evidence.

## Forbidden scope

Treating this WP as the first Quaternius adoption point, full-pack ingestion, whole street/town production, finished wardrobe/vehicles, bar interior production, broad artistic remodeling, arbitrary transformation factory, gameplay/controller logic, unverified content or hidden source archives committed contrary to license policy.

## Architecture / authority boundary

The exact Quaternius Source distribution has already been accepted at H1-04. This WP may expand the admitted subset only within that accepted source/distribution boundary or must record any genuinely new source/version as a new dependency adoption under `DEPENDENCY_IP_POLICY.md`.

Quaternius Source is editable upstream for later Juego2 art production, but H1-11 does not own the Cantabrian derivative-art pipeline. It proves the bridge can faithfully consume the representative real shapes. Future Juego2-derived assets remain ordinary separately identified catalogue inputs with traceable provenance, never Arkus semantic authority.

## Acceptance criteria

- every selected item is traceable to the accepted H1-04 source/adoption record (or an explicitly reviewed extension of it);
- every selected item has a stable logical catalogue ID and truthful native mapping;
- one small street-corner/humanoid slice materializes with hierarchy, prefab, material and component relationships intact;
- pivot/scale/import assumptions are explicit and validated;
- humanoid plus idle/walk/sit bindings inspect and reload without missing references;
- clean reconstruction reproduces normalized semantic parity;
- removing/replacing one selected asset yields actionable missing/incompatible diagnostics, not silent substitution;
- no H2 gameplay, exact CITY-03 seed or keeper-town geometry is introduced.

## Deterministic proof / evidence

Run the accepted clean-checkout -> source resolve/import -> canonical bind -> materialize -> validate -> save/reload -> inspect -> delete generated -> rebuild flow over the representative Quaternius slice. Preserve normalized evidence and one supplementary rendered capture; screenshots are not the parity oracle.

## Causal negative-conformance classes

- selected asset cannot be traced to accepted source/adoption provenance;
- asset omitted from the representative import/proof universe;
- pivot/scale or nested hierarchy lost;
- material or animation reference silently missing;
- logical ID replaced by asset path;
- purchased upstream source asset modified by bridge projection;
- rendered-looking success hides normalized parity failure.

## Content-shape probe

This WP is the broad representative real-source content-shape proof. It uses approved Juego2 material/constitution relationships but remains disposable bridge evidence, deliberately smaller than the H2 playable demo or CITY-07 keeper realization.

## Residual risks

Unselected pack content, finished character clothing/wardrobe, production variants, bespoke Cantabrian architecture/props, missing gameplay animations, production LOD/performance, visual polish and final animation behavior remain H2/ART/CITY production concerns.

Reopen H1-04 if source/catalogue identity or initial adoption provenance is false. A missing production-art feature becomes downstream scope, not automatic H1 failure.
