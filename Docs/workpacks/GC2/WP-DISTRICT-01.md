# WP-DISTRICT-01 — Expand the first port-town neighbourhood

Status: **PROPOSED / NOT_STARTED**
Class: PRODUCT / incremental keeper production
Depends on: `WP-GC2-SLICE` PASS and accepted CITY-URBAN district/seam plan

## Claim

Grow from the first block to an adjacent connected neighbourhood/district portion with more streets, interiors, businesses, named people, activities/jobs/minigames and a second investigation reason to revisit. Each added block must state the place, player action and reused composition or system.

Set a measured **active population/residency budget** before planning the other neighbourhoods. Validate that routine-bearing NPCs outside the active residency set remain abstract and can later materialize at the correct district/POI/time with their meaningful state intact. Measure authoring cost for routine templates and exceptions as well as runtime cost. Track new Arkus facts only for interactions whose consequence warrants it; a lightweight routine by itself is not a reason to make an NPC deeply systemic.

**PASS evidence:** third-person continuous traversal across blocks, one new playable business/activity and investigation branch, return-state change, at least one cross-neighbourhood routine/residency transition, observed reuse/authoring effort against first assembly, active-density/performance context and owner acceptance. **Evaluation:** playable review plus CITY/ART and targeted authority/residency checks. **FAIL if** adjacent streets are empty scenery, new geometry silently violates CITY access/seams, the old living block loses its remembered outcome, or scaling assumes all whole-town NPCs remain graphically alive at once. **Allowed residuals:** other neighbourhoods, final overall NPC count and final routine coverage beyond the measured production target.
