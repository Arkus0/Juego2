# H2F execution order and locality

This note is operational guidance for the accepted H2F plan. Individual WP contracts remain authoritative.

| WP | Purpose | Default execution | Can start before ART-01 PASS? | Requires owner's local/source assets? |
|---|---|---|---|---|
| `WP-H2F-00` | capability ecosystem survey + candidate register | `REMOTE_OK / RESEARCH_BATCH` | **Yes**, research only | No, except inspect existing documented Source capabilities where available; unknown local-only facts become evidence gaps, not guesses |
| `WP-H2F-01` | decision spikes + final stack selection | `HYBRID / PRODUCT_CHECKPOINT` | Research prep yes; keeper-source fit claims no | **Yes where needed** for real Quaternius/Unity visual, import, animation or interaction comparison |
| `WP-H2F-02` | exact adoption + URP/toolchain bootstrap | `HYBRID`, often `LOCAL_UNITY_REQUIRED` | No | **Yes** for account/licensed/local-only sources and effective Unity migration evidence |

| `WP-H2F-GATE` | foundation freeze | `HYBRID` | No | Uses the accepted effective evidence; clean restoration may combine hosted/repository proof with documented lawful manual provisioning |

## Immediate discovery seed, not preselection

H2F-00 must at minimum evaluate the capabilities already identified as plausible high-value inputs, without treating this list as the answer:

- Unity 6.3 URP and its native Volume/post-processing, decals, SSAO, Shader Graph and probe/GI facilities;
- Cinemachine 3;
- Input System;
- Unity Splines;
- AI Navigation;
- Terrain Tools;
- Animation Rigging;
- Timeline;
- ProBuilder as a bounded gap/transition authoring tool rather than the keeper architectural language;
- Quaternius Source project functionality/content before duplicate adoption;
- serious free animation options and Mixamo-style gap filling where lawful/compatible;
- vegetation/scatter options, fake-interior/window-depth options and CC0 material/texture sources;
- later/deferred narrative candidates such as Ink only if their present adoption would materially constrain H2;
- local behaviour-tree tooling only as downstream execution, never as Arkus canonical NPC authority.

The survey must add/remove candidates based on current evidence. This seed exists only to ensure already-known opportunities are not accidentally omitted.
