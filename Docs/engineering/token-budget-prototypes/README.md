# Token-budget prototypes — NON-CONTRACTUAL

These two files are measured prototypes for the token-savings work. They are
**not** sources of truth, **not** workpack contracts, and nothing may cite them
as authority. `Docs/ROADMAP.md`, `Docs/workpacks/**` and accepted evidence
remain authoritative.

- `PROJECT_STATE.prototype.json` — machine-readable project state, generated by
  parsing `Docs/ROADMAP.md` + `Docs/workpacks/README.md`. It exists to measure
  the token cost of structured state versus the current prose. Its extractor is
  a sketch: some `pr` / `review` fields are `null` where the regex did not match.
  In a real adoption the direction reverses — the state file becomes the source
  and the prose index is generated from it, so DocSync writes one row instead of
  the same SHA in up to 13 files.

- `INHERITED_CONTRACT.WP-HK-GATE.prototype.md` — what a downstream workpack
  actually needs to inherit from an accepted predecessor: exported guarantees,
  ownership warning, what is not covered, and the reopen condition. Written by
  hand from `Docs/workpacks/HK/WP-HK-GATE.md` and `Docs/evidence/WP-HK-GATE/`.
  It restates accepted content; it does not create or weaken any guarantee.

Adopting either one is a process decision that belongs in a workpack, not here.
