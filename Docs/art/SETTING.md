# Setting note — fictional Potes / Liébana

Status: product intent (not a gameplay design doc)  
Date: 2026-09-19

## Anchor

The playable town is a **fictionalized Potes in Liébana** (Cantabria):

- Mountain valley, river/bridge grain, stone streets
- Market-town density, not a fishing port
- Picos / green slopes on the skyline
- Humid, overcast-biased light

It is **not** a 1:1 reconstruction of real Potes, and **not** primarily Castro Urdiales / coastal Cantabria.

## Implications for art

| Prefer | Deprioritize |
|--------|----------------|
| Valley town fabric (Potes refs) | Harbour / quay / boats as hero identity |
| Stone + dark tile + timber balconies | Mediterranean or alpine chalet |
| River or stream edge (optional later) | Open sea as default backdrop |
| Market / bar / workshop life | Tourist-postcard “pueblo marinero” only |

Visual bible one-liner and refs index follow this anchor.
