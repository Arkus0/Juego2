# Visual refs — curated index

Date: 2026-09-19  
Purpose: fill `Docs/art/Refs/` without committing large binaries or non-free game screenshots.  
Rule: these are **direction inputs only**, not game assets. Prefer opening the Commons file page and downloading a **small** JPEG if you want pixels in-repo later.

## How to use

1. Read the bible one-liner and Yes/No in `Docs/art/VISUAL_BIBLE.md`.
2. Open the links below when triaging architecture, palette, sky, or “does this read Cantabria?”.
3. Optional: download 1–2 images per folder into the matching subfolder with name `NN_topic_source.jpg` and a line in that folder’s `SOURCES.md`.

## Free vs not free

| Kind | In this index |
|------|----------------|
| Wikimedia Commons / NASA (free licenses) | Direct file links |
| Commercial game screenshots | **Names only** — search yourself; do not commit rips |
| Stock (Alamy, iStock) | Not used |
