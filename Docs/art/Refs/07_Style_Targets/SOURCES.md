# 07 — Style targets (game look)

Retrieved: 2026-09-19  
**Do not commit copyrighted game screenshots to this repo.** Search these titles yourself and keep references local or as private moodboards.

## Feel targets (aligned with bible)

| Priority | Reference | Take this | Avoid taking this |
|----------|-----------|-----------|-------------------|
| High | **Yakuza / Like a Dragon** (town streets) | Density of life, readable facades, social space | Photoreal skin, neon Tokyo as palette |
| High | **Alba: A Wildlife Adventure** | Soft Atlantic-adjacent light, friendly low-poly town | Over-cute animal mascot as player default |
| Medium | **Townscaper** (mood only) | Chunk of silhouette, wet color blocks | No gameplay systems; pure toy |
| Medium | **Spiritfarer** towns/docks | Soft overcast, quiet coastal staging | Boat-as-whole-game scope |
| Medium | **Quaternius** official pack pages | Actual mesh/atlas language you will use | Unfiltered fantasy/sci-fi variants |
| Low | Shenmue HD | Interaction clarity, lived-in streets | Dreamcast/PS2 hardware look as mandatory render |

## Explicit non-targets

- Uncharted / Last of Us / photoreal PS3–PS5
- Ghibli-perfect painterly (unless a single prop)
- Pure Dreamcast low-res buffer aesthetic

## Free style samples you *may* screenshot for private use

- Quaternius pack pages (identify meshes; do not vendor the pack as a pack)
- Kenney.nl sample scenes (CC0) if you need neutral low-poly lighting tests
