## 0. Question and recommendation

PA-09 asks:

> How can meaningful player actions alter material, social or institutional world state and produce later consequences through the same causal contracts used by NPCs, without quest-specific magic, omniscient reactions or a parallel player-state universe?

**Recommendation:** treat the player as a **first-class initiator of semantic world actions**, not as a privileged writer of downstream state.

```text
player or NPC initiator
        ↓
semantic world action with real target/context/preconditions
        ↓
owned immediate world/material/activity outcome
        ↓
legitimate perception / communication / experience
        ↓
normal owners update their own state
        ↓
PA-02 actors make later choices for their own reasons
        ↓
chain may continue after initiating player leaves
```

Initiator identity, capability, authority, relationship, witnesses, consent and context may legitimately matter. What must not matter is a hidden semantic split where an NPC uses the Living World but the player uses `questFlagPlayerDidX` for the equivalent act.

PA-09 also adopts the embodied-actions amendment: dialogue is one action family, not the universal adapter. A small number of high-value physical/social actions should create causal world changes without implying an “everything is interactive” sandbox.

This is research/product guidance, not an input scheme, final action API, combat design, crime simulation, save format or runtime architecture.

## 2. Semantic player/NPC action equivalence

PA-09 adopts an **origin-neutral consequence rule**:

> When a player and an NPC perform semantically equivalent accepted world actions under equivalent capability/authority/context, the immediate owned world outcome must enter compatible causal owners.

Conceptually, a world action needs enough information to identify:

```text
initiator identity and actor kind
semantic action family
real target/place/resource/participant
preconditions / authority / consent where relevant
immediate owned outcome
observable facts / witness opportunity
bounded causal reason
```

This is not a frozen API.

Legitimate player/NPC differences may come from capability, authority, possession/access, relationship/obligation, physical context, consent, witnesses or later actor-specific interpretation. They may not exist merely because one initiator is player-controlled and therefore bypasses normal owners.

## 3. High-value intervention families

PA-09 does not freeze controller verbs. It defines semantic families that can earn implementation when they create reusable consequences.

### 3.1 Material / opportunity

- give / return / take where ownership matters;
- carry / deliver a relevant resource;
- occupy / reserve / release a scarce opportunity;
- enable / disable / block / clear a bounded useful state;
- help / hinder / repair where a real service/material owner exists.

### 3.2 Social / embodied

- invite / refuse / accompany / follow for a bounded purpose;
- greet / signal / show / offer where interpretation matters;
- join / leave a group or socially meaningful space;
- physically assist / intervene / protect where context warrants it.

Dialogue may negotiate or explain these acts; it is not required merely because no other interaction exists.

### 3.3 Activity

- join an existing activity;
- invite/challenge;
- occupy/release activity capacity;
- produce an activity-local result that PA-08 converts to a structured outcome.

### 3.4 Institutional

Future mayoral/policy actions may alter rules, access, service windows or opportunities through their governance owner. Authority changes conditions; it does not directly choose citizens' beliefs or actions.

### 3.5 Martial / conflict — future semantic family only

PA-09 preserves the amendment requirement that later physical conflict support contextual/graded aftermath and rejoin the same consequence universe. It does **not** research combat controls, damage or crime law here.

A later combat result that matters socially/materially must emit normal owned facts such as injury, witnessed conduct, damaged property, protection/help or access consequences instead of living in a combat-only reputation/quest island.

## 4. Decisive composed scenario — player → NPC → NPC without quest magic

The B1 canonical research fixture composes all three units at Bar F01.

Starting state:

- Bar F01 is inside an operating window;
- coarse `bar-service-stock` is missing after a delayed delivery;
- PA-07 exposes affected service as degraded/unavailable;
- Carmen has normal expected work context;
- Antonio later has a social/leisure opportunity;
- Manolo can be a card participant.

The player uses a valid **non-dialogue embodied action** to carry/return the delayed stock to its service point. PA-07 records the same semantic restoration an authorized NPC helper/delivery action would record. No `playerRestoredBar=true` flag is required.

After the player leaves:

1. Carmen can encounter restored service state and PA-02 may choose normal service work instead of fallback.
2. PA-07/08 can expose the relevant bar/activity opportunity.
3. Antonio later encounters it and PA-02 may choose cards.
4. Antonio may invite Manolo; Manolo owns accept/refuse.
5. A played card session emits only PA-08's bounded structured outcome.

The chain survives player absence because each transition is carried by shared state/opportunity and actor-owned decisions, not by a script attached to the original player input.

This satisfies the required bounded `player → NPC → NPC` research chain and a non-dialogue causal intervention.

## 5. Player-vs-NPC semantic-equivalence counterfactual

Run the same material/context state twice:

- **Run P:** player validly returns the missing service stock.
- **Run N:** eligible NPC validly returns the same stock under equivalent authority/capability/material conditions.

Required immediate invariant:

```text
missing dependency -> restored dependency
service degraded/unavailable -> restored condition as PA-07 rules permit
```

Later reactions may differ only where initiator identity is legitimately known and actor relationship/role/context differs.

Forbidden split:

```text
NPC path -> shared material owner -> actor decisions
player path -> private quest flag -> bespoke reactions
```

## 6. Perception, knowledge and conditional reaction

A player action does not imply universal knowledge.

Material consequences may be independently encountered: an actor can discover that a resource is restored, a route blocked or a service open without knowing who caused it.

Attribution requires legitimate access: direct witness/experience, explicit communication, public/institutional record where applicable, or later bounded inference accepted by its owner. Debug provenance knowing “the player did it” does not grant that fact to every actor.

Thus one intervention can produce a material consequence for everyone who later encounters changed state, while social attribution affects only actors who legitimately perceive/learn it.

## 7. Embodied agency findings

### Dialogue is not mandatory for meaning

The Bar F01 carry/return fixture demonstrates the core need: restoring a shared dependency should not require choosing “I delivered the stock” in dialogue if the meaningful gameplay act is carrying/returning it.

Other high-value semantic candidates include occupying/releasing a useful spot, accompanying someone, returning an object, helping unload/setup, standing between actors in conflict, or blocking/clearing a route where content supports it.

### Context owns interpretation

The same physical act may mean something different because of ownership, consent, role, relationship, place or danger. PA-09 rejects global mappings such as:

```text
TAKE -> theft
FOLLOW -> suspicious
PUSH -> assault
WAVE -> affinity + 1
```

The semantic action carries context; downstream owners determine legitimate consequences.

### Affordance density over prop quantity

Many pickupable decorative props do not satisfy embodied agency if they change no meaningful opportunity/person/access/shared state. Prefer fewer verbs that repeatedly compose with people, places, capacity and material state.

## 8. Recovery and intentional transformation

Ordinary intervention may cause service degradation, waiting/substitution, a request to stop/leave, relationship/obligation input where legitimately perceived, restitution/repair, or later recovery through normal owners. No unconditional reset is required; one low-salience mistake also need not automatically collapse the campaign.

Repeated meaningful action may keep changing owned state after feedback. Stabilizers must not secretly erase causes merely to restore the default town. PA-09 owns expressive causal entry; later PA/runtime work owns propagation, scale and stabilization budgets.

## 9. Legibility without omniscience

A useful debug trace may know the full causal chain:

```text
player action
 -> PA-07 material state
 -> Carmen decision
 -> PA-08 opportunity
 -> Antonio decision
 -> Manolo response
```

Player-facing evidence is different and may only expose what the player can legitimately observe/learn: service functioning, changed actor behaviour, visible use of the bar/table, a knowledgeable NPC mentioning the help, or changed access/opportunity. Debug lineage is not automatically player knowledge.

## 10. Quest-magic hard negative

This shape fails even if the visible scene looks correct:

```text
onPlayerReturnsStock:
    questFlags["player_fixed_bar"] = true
    Carmen.relationshipToPlayer += 10
    Antonio.nextActivity = "cards"
    Manolo.dialogueBranch = "bar_fixed"
```

It fails because material truth is private to a quest flag, relationship ownership is bypassed, actor choices are commanded, downstream continuation depends on bespoke script, and equivalent NPC help would need another semantic path.

A quest may observe or constrain systemic state for authored narrative. It cannot be the sole carrier of ordinary causal truth already owned by shared systems.

## 11. Mechanism decisions

| Mechanism | Disposition | Reason |
|---|---|---|
| Player as first-class semantic action initiator | **ADOPT** | Core playable-causal-city requirement. |
| Origin-neutral immediate owned outcome | **ADOPT** | Prevents player/NPC parallel universes. |
| Actor identity/context may alter later interpretation | **ADOPT** | Equivalence is semantic, not identity erasure. |
| Non-dialogue material/embodied intervention | **ADOPT** | Prevents talk-or-hit design. |
| High-value contextual action families | **ADOPT** | Gives composability without prop-sandbox explosion. |
| Consequences continue after player leaves | **ADOPT** | Required for genuine Living World causality. |
| Debug trace separate from actor/player knowledge | **ADOPT** | Preserves PA-04/05. |
| Recovery/repair through normal owners | **ADOPT** | Makes consequences playable rather than reset magic. |
| Private player-only quest flags as ordinary world truth | **REJECT** | Fails semantic equivalence. |
| Direct player mutation of NPC belief/relationship/future action | **REJECT** | Steals downstream ownership. |
| Dialogue-only interaction surface | **REJECT as product boundary** | Embodied amendment forbids it. |
| “Every prop interactive” as agency metric | **REJECT** | Causal yield matters more than raw count. |
| Global reputation as sole social consequence authority | **REJECT** | Cannot replace actor-local knowledge/typed relationships. |
| Combat as separate consequence universe | **REJECT for future integration** | Martial outcomes must later rejoin normal owners. |
| Final controls/action catalogue/combat/crime/governance model | **LATER** | Outside PA-09 research scope. |

## 14. Unit conclusion

PA-09 turns the Living World from something the player watches into something the player can **touch causally**.

The decisive test is:

> If an NPC can validly change shared material/activity state and cause later people to act differently, can the player perform the semantically equivalent world action through the same owner — and can consequences continue after the player leaves?

For the B1 research model, yes. Any future implementation requiring a private player-only quest path for the equivalent action reopens PA-09's core claim.
