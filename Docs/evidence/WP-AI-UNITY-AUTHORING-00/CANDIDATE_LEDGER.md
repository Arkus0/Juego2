## Additional discovery audit

- AnkleBreaker is included above after auditing the exact license's internal commercial-use permission. A commercial Arkus tool/service that redistributed its code would be a separate licensing question; it is not needed to test whether Juego2 can use the operator internally.
- [Signal-Loop UnityCodeMCPServer](https://github.com/Signal-Loop/UnityCodeMCPServer) is MIT and offers live reads/Play observation, but its README identifies `execute_csharp_script_in_unity_editor` as the mutation path for GameObjects, prefabs, assets and import settings. This is a potentially valid **code-execution operator** for the replacement question. It is not part of the primary minimum set because its narrow-tool authoring coverage differs materially from the direct Editor APIs of the three mandatory candidates. If tested, keep broad code execution and all generated C# visible in the operation log; do not credit it as no-code native authoring.
- [FunplayAI funplay-unity-mcp](https://github.com/FunplayAI/funplay-unity-mcp) is MIT, release `v0.6.9` (2026-09-17), package `com.gamebooom.unity.mcp`. Its package identity and README reproduce the earlier GameBooom/KitWright lineage; [KitWright's changelog](https://github.com/kitwright/unity-mcp/blob/main/CHANGELOG.md) records the rebrand and its newer `v1.0.0` package. No additional required ENV/CHAR/ANIM operation was identified beyond that newer lineage, so the older variant is excluded as a duplicate surface rather than silently counted as a fourth independent operator.
- [emeryporter UnityMCP](https://github.com/emeryporter/UnityMCP) is GPL-3.0. GPL terms alone do not establish that an independently run development tool is unusable for commercial game production. Its source/package maintenance and exact proposed use require a separate comparison/IP review; it is not excluded solely to preserve Arkus platform licensing.
- [Unity's plugin for third-party agents](https://docs.unity.com/en-us/ai/unity-plugin/about-unity-plugin) provides agent skill instructions, not an Editor MCP/CLI/package connection by itself. It is not a comparable operator surface and is excluded. The newly added Unity CLI + Pipeline row above covers Unity's current first-party Editor-control path.

The trial ledger will record every package manifest/lock change and any new candidate or exclusion discovered before final comparison. No trial candidate is installed into the accepted project baseline.
