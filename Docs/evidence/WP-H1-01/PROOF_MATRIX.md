## Central claim

For the finite initial H1-01 binding vocabulary, one versioned portable Unity-scoped producer normalizes target logical scene, local transform, logical prefab/asset source and allowlisted component documents; mechanically derives every structured canonical-object and catalogue reference it understands; rejects caller dependency assertions that do not exactly match derived truth; encodes/decodes the normalized binding deterministically; and contributes compile/decode/inspect routes through the accepted canonical composer. The producer emits only an ordinary H0 extension mutation fragment and never becomes canonical write authority.

## Independently evaluated universe

The completeness universe is the explicit v1 binding grammar, not a producer-owned mutable registry: target scene; source asset/prefab; transform; `canonical-link(relation,targetObjectId)`; `renderer(materialId)`; and `animator(clipId)`. The Potes fixture's expected canonical/catalogue reference sets are authored independently of derivation code. Process-level JSONL/MCP conformance discovers the composed inventory independently through each transport. Contract pin tests protect the public version, the admitted v1 component vocabulary and portable assembly boundary.

## Causal-control discipline

Every source mutation is made in a disposable detached worktree. `expect_red` rejects compiler, MSBuild and NuGet errors as invalid evidence; a control counts only when the named focused test reaches test execution and fails. The worktree is reset after every mutant and must be clean at completion. The first Worker attempt exposed this distinction correctly: an `if (true) continue` seed caused compiler `CS0162` and was rejected as non-causal; the control was repaired to a runtime-always-true expression so the semantic test, not compilation, owns the RED. The same-version control was also strengthened during Worker pre-review: it now changes the admitted component schema while preserving every public version identifier, so its RED is caused by undetected semantic widening rather than by an explicit version-string change.
