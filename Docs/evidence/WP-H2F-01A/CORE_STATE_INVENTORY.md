# Core state inventory — what GC2 Core stores and generates

This table lists every state family that GC2 Core creates, stores or requires in a project that uses the admitted capabilities. It was observed in C01–C07. The **lifecycle hint** column is input for H2F-02, which owns the H1 lifecycle classification and host. It is not that classification.

The kinds are:

- **vendor**: bytes provisioned from the licensed package;
- **generated**: created by GC2 from defaults;
- **authored**: written by a Juego2 author or tool through the serialized surface;
- **transient**: created at play time and never serialized.

| # | State family | Location | Kind | Observed | Canonical-identity risk | Lifecycle hint for H2F-02 |
|---|---|---|---|---|---|---|
| S1 | Core code and bundled Core content (scripts, `Mannequin.fbx`, locomotion clips, `Skeleton.asset`, `Footsteps.asset`, gizmos, controllers) | `Assets/Plugins/GameCreator/Packages/Core/**` | vendor | C01 (3,630 imported entries) | none | Externally provisioned dependency: never committed; restored from the pinned package through the Assets-only route; hash-checked. |
| S2 | Core settings assets `core.general` (save storage/encryption/load mode, audio mixers), `core.variables`, `core.updates`, `core.welcome` | `Assets/Plugins/GameCreator/Data/Resources/Settings/` | generated at the first windowed editor load; `core.general` becomes **authored** once Juego2 selects a storage backend (C06) | C01 windowed, C06 | none (no IDs) | Project configuration generated from defaults. If Juego2 overrides `core.general` it becomes a declared, committed project setting with an expected value. The other three are editor-only and may be regenerated. |
| S3 | `Character` component serialized state: `m_IsPlayer` and the kernel units (player input unit and its input binding, motion height/radius/speed, driver, facing, animim); footsteps (feet bones, sounds asset reference, detector); ragdoll system configuration; IK rig list; interaction mode | on the player/NPC scene objects or prefabs | authored (C02–C07 builders, serialized paths in `PUBLIC_AUTHORING_SURFACE.md`) | C02–C07 | none: C02/C07 identity audit found **no** ID/GUID/save-id field on any GC2 component in the scene | Bridge-realized presentation of a Juego2 character. It is materialized from a Juego2 character preset and reconciled only as a presentation projection, never read back as canonical. |
| S4 | Character model instance under `Mannequin` | child of the Character | generated by `ChangeModel`, which **instantiates a copy** (not a prefab link) | C02 | none | Generated from the model prefab input. Rematerialize from the preset. Edit-mode `ChangeModel` needs the H2F-01 workaround (remove the old animator object first). |
| S5 | Components GC2 adds at play start: hidden `CharacterController` (UnitDriverController), `NavMeshAgent` (UnitDriverNavmesh), `InteractionTracker` (Trigger On Interact, at Awake), kinematic `Rigidbody` (Trigger physics events), animator proxy, ragdoll bone colliders/rigidbodies | on the Character/Trigger objects at runtime | transient | C02–C07 (`character_controllers=1` for the player; NPC uses the agent) | none | Transient. Must not be serialized or reported as unsupported drift by H1 observe/reconcile. |
| S6 | Trigger/Hotspot/Actions/Conditions serialized data: event and instruction lists as `[SerializeReference]` polymorphic entries, including Juego2 adapter entries that hold Juego2 keys (`j2.door.probe:state`, `j2.lamp.c05`) | on scene objects | authored | C03, C05, C07 | Juego2 keys are Juego2-owned strings. GC2 stores them opaquely and assigns no identity of its own. | Authored local-execution configuration of a presentation object. Serialized polymorphic entries record adapter type names (class/namespace/assembly). Renaming an adapter class breaks them unless it is marked `[MovedFrom]`, so adapter type names are part of the frozen seam. |
| S7 | `MaterialSoundsAsset` (texture key `_BaseMap`, ART textures → clips) | project asset (Juego2-authored) | authored | C04, C07 | none | Juego2 project asset whose inputs are ART textures and audio. |
| S8 | Ragdoll inputs: GC2 `Skeleton.asset` and the Core recovery clips `Human@Action_StandFace{Up,Down}` | vendor content referenced by S3 | vendor | C04, C07 | none | Vendor content referenced by authored configuration. Provisioned with S1. |
| S9 | GC2 locomotion state assets and controllers (`CompleteLocomotion.controller`, `State*` assets) | vendor | vendor | C04 (comparison walker only) | none | Not retained. Juego2 characters use the UAL controller (`REDUNDANT_WITH_SELECTED_STACK`). |
| S10 | Juego2 input action asset referenced by the GC2 player unit | Juego2 project asset | authored (Juego2) | C02, C03, C07 | none | Juego2-owned input configuration. GC2 only reads it. Juego2 enables/disables it. |
| S11 | GC2 Variables (Global/Local Name/List) | assets/components if used; saved under `data-NNNN-global-*-variables` | authored/runtime | C06: GC2 writes its own global-variables keys into **every** save even when unused | high if used for world facts | Local, presentation or session only. Never a keeper fact. If one is ever used, it is declared as presentation state. |
| S12 | GC2 save data: `data-0000-slots`, `data-0000-volumes` (shared), `data-NNNN-scenes`, `data-NNNN-global-*-variables`, `data-NNNN-<IGameSave id>` | wherever the configured `TDataStorage` writes. Default is **PlayerPrefs** (Windows registry); C06 used the Juego2 workspace JSON backend. | runtime user data | C06, C07 | the `scenes` key and GC2 load semantics own scene loading (see the authority boundary) | Not project state. If H6 ever adopts the host, the storage location is Juego2-owned and the scene-reload coupling needs an explicit decision. |
| S13 | Runtime singletons (Application/Async/Audio/Input/EventSystem/Pool/Schedule/Time/Update/Room managers, SaveLoadManager, global variables managers, Console) and spatial hashes | `DontDestroyOnLoad` objects created by `RuntimeInitializeOnLoadMethod` | transient | C02–C07 | none | Transient runtime infrastructure. Present in every play session once Core is installed. |
| S14 | `Remember` / Memories / Tokens | components if used | would be authored, plus save data keyed by GC2 unique IDs | not used (rejected) | **high**: a GC2-keyed persistence of world-object state | Not admitted (`REJECT_CAPABILITY`). An H2F-02 lint should forbid `Remember` on keeper objects. |

Evidence that nothing canonical crossed into GC2:

- `results/c02_result.json` and `results/c07_result.json`: `gc2_identity_fields_in_scene=""` and `arkus_binding_keys_unique=true`.
- `results/c06_result.json`: the stored payload is the Juego2 schema `juego2.h2f01a.probe-payload@1`; a foreign version is refused by Arkus.
- `results/c05_result.json`: stock GC2 instructions ran only after an Arkus-accepted transition.
