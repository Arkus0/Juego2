## Claim boundary and independently evaluated universe

The managed scene is the single fixed logical target `arkus.h1-05.scene.potes`. The canonical object universe is every `arkus.unity-binding@1` object extension in the current accepted H0 `WorldState`, obtained from the state rather than from a scene marker registry. Every bound object's canonical container must also be bound. The effective Unity universe is independently enumerated by loading the manifest-selected scene in a fresh Editor worker, walking its effective root and all `H1ManagedMarker` components, and rejecting missing/duplicate/invalid markers. The source catalogue is independently captured from the H1-04 reviewed AssetDatabase roots and compared with the exact accepted 250-entry inventory before each Editor materialize or observe phase; the H1-04 mapping/adoption contract supplies logical-to-native source identity.

The plan is versioned and anchored to canonical world hash/revision and catalogue fingerprint. `ManagedScenes/generations/<id>.unity` is disposable derived output; only `ManagedScenes/current.json` selects the active generation. The manifest is published after scene save, reload, marker enumeration and normalized plan comparison. Its graph digest is checked on subsequent observation. Source assets and the canonical session are never written by the projection worker. The fixture uses the approved Quaternius facade model prefab; root/marker components are harness-owned mechanics.
