# WP-HK-08A residual risk

## Claim boundary

HK08A claims efficient stable interaction primitives over the already accepted H0 authored-world semantics: one representative 96-operation mixed-resource intent remains one atomic validated/provenanced transaction; public journal reads are bounded/paginated with deterministic continuation tied to the authored journal context; compact reads and canonical discovery support economical interaction; and all changed public shapes remain semantically equivalent through JSONL and MCP.

The proof boundary includes repository-owned canonical contracts/services, the HK08A public provenance wrappers, Runtime composition, both accepted local transports and the focused/full conformance suite. It trusts the accepted predecessor semantics, Git/exact-checkout behavior, pinned .NET toolchain, normal process/stdio behavior and documented hashing primitives under the foundational proof standard.

Within that boundary, no known material false-green defect class remains after the Worker pre-review repairs and exact implementation observation.

## Non-blocking residuals / named future owners

### 96 operations is not the final resource envelope

The 96-operation maximum is justified only as the smallest current bounded envelope needed by the representative HK08A mixed-resource probe. It is not a performance promise and not a permanent semantic constant. HK09B owns measured bytes/depth/time/page/batch limits using accepted HK08A/HK08B representative shapes.

### Stale-CAS recovery is still HK08B

HK08A cursor stale handling is read-pagination correctness. It does not add structured recovery for a mutation planned against an old whole-world revision/hash, automatic merge, diagnostic repair ordering or bounded reinspection strategy. Those are explicitly HK08B.

### Paging bounds the public response, not internal journal storage

The current process-local provenance authority still owns/materializes its complete HK06A journal, and the HK08A paging view slices that accepted artifact. HK08A reduces wire/client interaction size and provides deterministic pagination; it does not claim incremental on-disk journal indexing, streaming persistence, unbounded-history memory scaling or crash durability.

### Large replay inputs require complete-artifact reconstruction

When a journal exceeds one public page, each partial response is deliberately marked `arkus.authoring.journal-page@1` so HK06C replay cannot mistake it for a complete journal. A client that wants to replay the complete history must deterministically collect pages and reconstruct the accepted complete HK06A artifact. HK08A does not introduce a second replay format.

### Cursor integrity is framing correctness, not authorization

Public continuation cursors are opaque values. Their deterministic envelope detects altered/corrupted cursor context such as an edited offset before it reaches the paging service. The checksum is not a secret MAC and HK08A makes no hostile-client, authentication or access-control claim. Deliberate fabrication of new opaque cursor values is outside the supported client contract; remote/auth security is outside H0.

### Process lifetime remains predecessor scope

JSONL/MCP hosts still use the accepted process-local authored session. Cursor lifetime across a process restart, durable project storage, multi-process writers and distributed coordination are not added here.

### Cost metadata is relative, not a final agent budget

`sideEffect` plus canonical relative cost is enough for machine-readable cheap-path discovery. It is not a measured token/latency budget, model-vendor policy or guarantee of a maximum number of agent calls. HK08B owns the representative correction benchmark and final interaction budgets.

### Product-shape probe is deliberately synthetic at the H0 semantic layer

The 72 object + 24 extension probe is sized from the approved-draft Potes/Liébana visual-bible envelope while remaining engine-neutral. It does not prove Unity transforms, real prefab identity, geometry constraints or asset import. Those are later bridge/content concerns and would be scope creep here.

## Blocking-risk conclusion

None of the residuals above can falsify the stated HK08A claim without either crossing into an explicitly later workpack or requiring unsupported behavior outside the accepted local/opaque-cursor contract. The one concrete in-boundary pagination false green found during Worker pre-review — editable cursor offset context — was repaired rather than residualized.
