# WP-DW-02 — residual-risk and proof-budget audit

PROOF_BUDGET_VERDICT: WITHIN_BUDGET

## Declared boundary

DW-02 proves deterministic production queries and a machine-readable content-shape report over the complete accepted CITY-02 §4 programme ledger. It owns exact source-manifest fields, complete subject/query/report membership, exact-row provenance, deterministic ordering/rebuild, classification movement and non-invention of production cost.

It does not claim realized geometry, actual art/prefab coverage, Unity object state, runtime schedules/access availability, gameplay quality, exact production cost, detailed CITY-05 parcel semantics or CITY-06 room/discovery semantics beyond inherited DW-01 guarantees.

## Blocking-risk audit

No known in-boundary defect class remains intentionally undetected:

- projection/query denominator self-shrink is blocked by source-owned required IDs plus independent source-side identity comparison;
- production parser omission is observable because the reference oracle parses source separately and compares exact tuples/IDs rather than production totals;
- `loc.*`-only reporting cannot self-confirm because all `fam.*` rows are required and an all-family omission control is RED;
- stale classification cannot hide behind cache because source mutation rebuilds and changes exact buckets/snapshot;
- values without accepted provenance are rejected; changed accepted bytes are stale under inherited DW validation;
- order dependence is covered by reverse-enumeration rebuild equality;
- absent cost data has a single explicit non-numeric state.

## Non-blocking residuals

- The source is Markdown with a reviewed bounded table shape. Intentional source schema changes fail closed and require adapter/manifest review rather than heuristic recovery.
- `loc.*` / `fam.*` are the accepted identity families currently present. A future new family will fail closed until the query contract deliberately adopts it.
- District strings are source labels, not a newly canonical district ontology.
- RD-1..RD-4 cannot be honestly measured without realized traversal/runtime evidence and are deliberately not inferred.
- Content-shape counts are design-implied demand proxies only; they say nothing about existing asset coverage or person-hours.

## Predecessor reopen audit

The full 37-row current programme is representable through the accepted generic DW identity/field/provenance surface. No query requirement forced a CITY semantic type/rule into H0, and no accepted DW-01 mapping/invariant assumption was contradicted.

Therefore **DW-01 is not reopened** and **DW-00/H0 are not reopened**.

## Proof-budget rationale

The material proof support maps directly to WP-DW-02 criteria: one production provider/query/report file, one focused independent-source test suite, one exact-SHA observer/verifier pair, a frozen query-suite declaration and compact foundational evidence. The two omission controls cover distinct causal completeness risks (single record and whole non-POI family denominator) rather than syntax variants. No general CITY parser framework, cost estimator, traversal simulator or Unity adapter is introduced.
