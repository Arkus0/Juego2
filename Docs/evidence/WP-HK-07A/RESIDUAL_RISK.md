## Non-blocking residuals outside the claim

The host owns an in-memory portable session. Restart recovery requires explicit accepted snapshot import and/or journal replay by the client. Durable storage, WAL/fsync, automatic restart recovery and lost-response durability are not HK07A claims.

### Admission-only cancellation and timeout

### Reference frame bound versus general resource policy

The 1 MiB input-line bound protects deterministic reference framing; it is not a canonical request-size rule or a general host resource-governance policy. Output size, large-world throughput/endurance and route-specific cost limits remain later work.

### File-mode containment and capability policy

`--file PATH` reads the exact caller-supplied input path and writes no file. Filesystem sandbox/allow-list policy, host capability exposure and path-containment policy belong to HK09A. HK07A guarantees only explicit input selection and stable inaccessible-file behavior.

### Multi-process and concurrent clients

The reference process consumes one JSONL stream sequentially over one process-local aggregate. Cross-process locking, distributed writers, multi-agent merge and a concurrency/throughput SLO are not claimed. The neutral admission gate prevents overlapping dispatch within one service instance.

### Second transport and MCP equivalence

The contract is intentionally framed without MCP types, but HK07A proves it through one reference adapter. HK07B owns the independent second-projection test: MCP must fit this accepted neutral contract without semantic amendment.

### Interaction efficiency and recovery ergonomics

Batching, pagination, compact output, stale-revision recovery and bounded correction workflows belong to HK08A/HK08B. HK07A transports the currently accepted canonical shapes without pre-cooking those future semantics.

### Authentication, networking and hostile process isolation

The reference host is local stdin/stdout with no network or authentication. It does not claim hostile caller isolation, encrypted transport, remote tenancy or OS sandboxing.

### Gameplay/runtime state

No claim is made for NPC simulation, scheduler/clock state, physics, animation, Unity scene state, networking or transient live-state persistence. The process exposes the accepted authored H0 contract only.
