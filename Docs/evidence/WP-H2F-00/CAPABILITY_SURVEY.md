## Scope and stopping rule

All 27 classes have a native/current baseline and a disposition. For classes 09, 12, 13, 25, already-owned Quaternius was checked *first* at the bounded effective H1 slice. Unknown full Source features are named as `G1` below, never assumed absent. Free/paid examples represent mechanisms that could change the decision; nearby Asset Store duplicates have the same authority/replacement/visual uncertainty and do not add an independent discriminator. A future specific option can still enter through an explicit H2F amendment.
